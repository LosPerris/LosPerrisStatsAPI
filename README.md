# LosPerrisStatsAPI

Plugin de estadísticas para **Paper / Spigot 1.20+**. Rankings, hitos, dashboard web, API HTTP y bot de Discord — todo modular: activa solo lo que uses.

**Versión actual:** 1.6.0 · [Descargar JAR](https://github.com/LosPerris/LosPerrisStatsAPI/releases/latest) · [Licencia MIT](LICENSE)

> ¿Quieres misiones, evolución, títulos, temporadas, eventos, hologramas, portales…?  
> Eso va en el addon **[LosPerrisExtras](https://github.com/LosPerris/LosPerrisExtras)** (se integra en los mismos comandos `/lpa`).

---

## Descargar

1. Baja el JAR desde **[Releases](https://github.com/LosPerris/LosPerrisStatsAPI/releases/latest)**  
2. Ponlo en la carpeta `plugins/` de tu servidor  
3. Arranca el servidor y listo

Opcional: [Vault](https://www.spigotmc.org/resources/vault.34315/), [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/), [DiscordSRV](https://www.spigotmc.org/resources/discordsrv.18494/).

---

## Qué incluye

| Módulo | Para qué sirve |
|---|---|
| **Stats & rankings** | Muertes, kills, bloques, playtime… leaderboards y consultas en juego |
| **Hitos** | Logros con rareza, efectos y galería |
| **Dashboard web** | Panel en el navegador para ver y administrar datos |
| **API HTTP** | Endpoints para webs, bots o paneles externos |
| **Página pública** | Ranking público sin entrar al dashboard |
| **Discord bot** | Panel del servidor, slash commands, embeds y botones |
| **Discord webhook** | Avisos automáticos a un canal |
| **Scoreboard** | Sidebar con variables del plugin |
| **GUI** | Menús de estadísticas en inventario |
| **Periodos** | Resets diarios / semanales / mensuales |
| **Historial & heatmap** | Tendencias y mapas de actividad |
| **AFK, backups, updates** | Control de inactividad, copias y aviso de versiones |

En el juego: `/lpa help` · `/lpa modules`
