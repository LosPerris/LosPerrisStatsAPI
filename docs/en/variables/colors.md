# Variables: Color codes

> File generated automatically from the plugin registry (`core/text/Variables.java`). Do not edit it: it is overwritten on startup.

**Used in:** Messages, milestones, scoreboard, prefix and web dashboard announcements  
**Syntax:** `&` codes before the text

| Variable | Description | Example | Valid in |
|---|---|---|---|
| `&0 … &9, &a … &f` | Minecraft colors | `"&aVerde &cRojo"` | Every text shown in game |
| `&l &o &n &m &k` | Bold, italic, underline, strikethrough, obfuscated | `"&l¡IMPORTANTE!"` | Every text shown in game |
| `&r` | Resets color and format | `"&cRojo&r normal"` | Every text shown in game |
